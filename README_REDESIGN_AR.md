# Celyah – Purple Glass UI (Flutter source)

## التعديلات المنفذة
- ثيم داكن أسود/بنفسجي مع حواف مضيئة وأزرار دائرية.
- الشاشة الرئيسية: وجه سيليا، الرسائل تحته، إدخال الشات، والتحكم اليدوي والذراع.
- أيقونة جديدة مبنية على صورة العينين المرسلة مع كتابة Celyah (خط بديل قريب؛ لا يتضمن ملف خط اللوجو الأصلي).
- 3 أقسام: الرئيسية، الكاميرا، الإعدادات. لا توجد صفحة شات مستقلة.
- صورة الحب تستخدم صورة العينين المرجعية المرسلة. بقية التعبيرات لا تزال مرسومة بواسطة EyePainter القديم؛ لا يوجد ادعاء بتطابقها بكسل-بكسل مع شاشة ESP32.
- بروتوكول BLE الحالي باقٍ، وحركة الاتجاهات تتوقف عند رفع الإصبع (DRIVE ثم STOP).

## غير منفذ بعد
- التحكم عبر الإنترنت من أي مكان: يتطلب خدمة وسيطة مؤمنة (MQTT/TLS أو WebSocket)، مصادقة، وتحديث firmware ESP32. لا يُفتح الراوتر للعموم.
- بث الكاميرا من خارج الشبكة المحلية غير منفذ.
- التزامن الحرفي لكل فريم من وجوه شاشة ESP32 غير منفذ. كود الوجوه الأصلي مرفق في reference_firmware للمراجعة فقط.
- مؤشر البطارية يعرض -- لأن بيانات BAT لم تُربط في هذه النسخة.

## بناء APK
ارفع المشروع إلى GitHub ثم شغّل GitHub Actions / Build Celyah V14 APK (اسم workflow القديم) أو استخدم Flutter محليًا. هذا المصدر لم يتم اختباره بعملية flutter build في هذه البيئة لعدم وجود Flutter SDK.

## ملاحظة أمان
التحكم في الحركة عن بعد يتطلب timeout داخل ESP32 وإيقافًا عند فقد الاتصال وحماية للحواف/العوائق. لا تستخدم الحركة الذاتية قرب السلالم.
